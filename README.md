# Crypto Exchange Demo

Демонстрационный криптообменник: публичный сайт + FastAPI + SQLite + Telegram-бот + админка.

> **Важно:** это demo/MVP. Реальных блокчейн-транзакций, вывода средств и production-безопасности здесь нет.

## Локальный запуск Windows

1. Скопируйте `.env.example` в `.env` и заполните свои секреты.
2. Запустите `INSTALL.bat`.
3. Запустите `START_ALL.bat`.
4. Сайт: `http://127.0.0.1:8001/`
5. Админка: `http://127.0.0.1:8001/admin`

## Онлайн-развёртывание

Для публичного тестирования репозиторий можно подключить к хостингу Python-приложений. GitHub хранит исходный код; сам FastAPI должен работать на сервере.

Секреты (`.env`, Telegram token и другие ключи) в репозиторий не добавлять.
