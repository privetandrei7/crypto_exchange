# Crypto Exchange — Clean Start

Демонстрационный криптообменник: публичный сайт + FastAPI + SQLAlchemy + база данных + Telegram-бот + админка.

## Что внутри

- публичная страница обмена;
- расчёт курса и комиссии;
- создание и отслеживание заявки;
- привязка заявки к Telegram;
- Telegram-бот;
- админ-панель;
- изменение курсов и комиссии;
- смена статусов заявки;
- история статусов и комментарии администратора;
- безопасная миграция старой SQLite-схемы `order_status_history`.

Поддерживаются BTC, ETH, USDT, USDC, EUR и RUB.

## Важно

Это **DEMO/MVP**. Реальных blockchain-транзакций, реальных кошельков и реальных выплат нет. Не используйте систему для хранения или перевода реальных средств.

Секреты не хранятся в GitHub: `.env`, токены и локальная база исключены через `.gitignore`.

## Windows

1. Скопировать `.env.example` в `.env`.
2. Запустить `INSTALL.bat`.
3. Запустить `START_ALL.bat`.
4. Сайт: `http://127.0.0.1:8001/`.
5. Админка: `http://127.0.0.1:8001/admin`.

## Онлайн

GitHub хранит исходный код, а FastAPI должен запускаться на Python-хостинге. Для web-сервиса команда запуска:

`uvicorn web:app --host 0.0.0.0 --port $PORT`

Для постоянного хранения заявок в публичном окружении рекомендуется PostgreSQL вместо временной файловой SQLite-базы.
